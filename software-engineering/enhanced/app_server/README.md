## About This Component

The server application provides the server-rendered portion of Travlr Getaways. It organizes request handling through controllers and routes and uses Handlebars templates to render the application's views.

The primary CS 499 role-based access control enhancement was implemented within the REST API and Angular administrative application. This server application remains part of the complete enhanced artifact and works alongside those components and the MongoDB data layer.
