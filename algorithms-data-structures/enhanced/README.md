
# Enhanced Artifact — CS 300 CourseManager

## AVL Tree Implementation and Prerequisite Validation

This is the enhanced version of my CourseManager application, developed for the CS 499 Computer Science Capstone.

The original binary search tree (BST) was upgraded to a self-balancing AVL tree to improve efficiency when inserting and searching for course information.

### Enhancements Implemented

**AVL Tree Balancing**
- Added node height tracking and balance factor calculations.
- Implemented left and right rotations to maintain tree balance.
- Added automatic rebalancing during course insertion.
- Improved worst-case search and insertion performance from O(n) to O(log n).

**Course Prerequisite Validation**
- Added validation to identify prerequisites that reference courses not present in the loaded dataset.
- Improved data integrity by identifying invalid course relationships.
