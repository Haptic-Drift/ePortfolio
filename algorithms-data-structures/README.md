
# Enhancement Two: Algorithms and Data Structures

## CS 300 — CourseManager

This artifact originated from CS 300: Data Structures and Algorithms. The original application used a binary search tree (BST) to store, search, and display course information.

For my CS 499 capstone, I enhanced the application by implementing a self-balancing AVL tree and adding course prerequisite validation.

### Enhancement Summary

The enhanced application uses AVL tree rotations to maintain a balanced tree structure during course insertion. This improves the worst-case performance of search and insertion operations from O(n) to O(log n).

The enhancement also adds prerequisite validation to identify references to courses that are not present in the loaded dataset.

These improvements demonstrate my ability to apply data structures and algorithms to improve software efficiency, reliability, and maintainability.
