
# Original Artifact — CS 340 Grazioso Salvare

## Animal Shelter Database and Dashboard

This is the original Grazioso Salvare project developed for CS 340: Client/Server Development.

The application uses Python and MongoDB to perform create, read, update, and delete (CRUD) operations on animal shelter records. A Jupyter Notebook dashboard provides an interface for retrieving and displaying animal data.

The publicly available source files have been sanitized to remove hard-coded database credentials while preserving the original implementation.
