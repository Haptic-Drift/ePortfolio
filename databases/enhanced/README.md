
# Enhanced Artifact — CS 340 Grazioso Salvare

## Search-and-Rescue Dashboard Enhancement

This is the enhanced version of my Grazioso Salvare project, developed for the CS 499 Computer Science Capstone.

The application integrates Python, MongoDB, and an interactive Jupyter-based dashboard to retrieve, filter, and visualize animal shelter records.

### Enhancements Implemented

**Database Integration and Configuration**
- Improved MongoDB connection configuration using environment variables.
- Removed hard-coded database credentials from the application.
- Added an `.env.example` file to document required connection settings.
- Improved database connection handling and error reporting.

**Dashboard Functionality**
- Implemented rescue-type filtering for water rescue, mountain or wilderness rescue, and disaster or individual tracking.
- Added a reset option to display all available animal records.
- Integrated an interactive data table and visualizations to support data exploration.
- Improved dashboard presentation and readability.

This enhancement demonstrates my ability to integrate MongoDB with Python applications, manage database connections securely, and develop interactive interfaces that support data-driven decision-making.

### Running the Application

The dashboard requires Python, the project dependencies, and access to a configured MongoDB database.

Connection settings must be supplied through environment variables. The `.env.example` file identifies the required configuration fields.

The GitHub Pages ePortfolio provides access to the source code and documentation; it does not host a running instance of the dashboard.
