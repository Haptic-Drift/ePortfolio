
# Enhancement Three: Databases

## CS 340 — Grazioso Salvare Search-and-Rescue Dashboard

This artifact originated from CS 340: Client/Server Development. The original project used Python, MongoDB, and a Jupyter Notebook dashboard to retrieve and display animal shelter records for search-and-rescue applications.

For my CS 499 capstone, I enhanced the database integration, connection configuration, and interactive dashboard functionality to improve usability and maintainability.

### Enhancement Summary

The enhanced application uses environment-based MongoDB connection settings instead of hard-coded credentials, improving configuration management and security.

The dashboard also provides rescue-type filtering, an interactive data table, and visualizations to help users explore animal shelter records.

These improvements demonstrate my ability to integrate databases with Python applications, manage data retrieval, and develop user interfaces that support data-driven decision-making.
