# Code Review

As part of my CS 499 Computer Science Capstone, I completed a code review of the artifacts selected for enhancement in my ePortfolio. The review examines the existing functionality of the artifacts, identifies areas for improvement, and explains the enhancements planned in the areas of software engineering and design, algorithms and data structures, and databases.

The code review also provides an overview of the code before the enhancements were implemented and discusses how the planned improvements relate to the computer science program outcomes.
